# Empty Base Optimization (EBO) & `[[no_unique_address]]`

## Проблема
В C++ любой самостоятельный объект (даже пустая структура `struct Empty {};` без полей) обязан иметь размер не менее **1 байта**, чтобы два разных объекта в памяти гарантированно имели разные адреса.

Когда такой пустой объект (например, stateless-аллокатор, компаратор или deleter в `std::unique_ptr`) становится полем класса рядом с указателем (`8 байт`), из-за правил выравнивания структуры (padding) этот 1 байт превращается в **8 байт потерянной памяти** (структура раздувается с 8 до 16 байт).

---

## Решение 1: Empty Base Optimization — EBO (C++11)
Стандарт C++ делает исключение для **базовых подобъектов**: если класс наследуется от пустого класса, компилятор имеет право выделить под базовый класс **0 байт**, совместив его адрес с началом производного класса.

В стандартной библиотеке на этом принципе построены `std::unique_ptr`, `std::vector` (хранение аллокатора) и `boost::compressed_pair`.

**Недостатки EBO:**
* Требует громоздкого шаблонного кода (обёртки вроде `CompressedPair`).
* **Не работает с `final`-классами** (от них нельзя унаследоваться).
* Не работает, если стратегия — указатель на функцию (не класс).
* Требует аккуратности, чтобы методы базового класса не пересекались с методами наследника.

---

## Решение 2: Атрибут `[[no_unique_address]]` (C++20)
В C++20 появился стандартный атрибут `[[no_unique_address]]`, который применяется непосредственно к нестатическому полю класса. Он разрешает компилятору перекрывать адрес пустого поля с адресами других полей объекта.

**Преимущества `[[no_unique_address]]`:**
* Пишется в одну строчку прямо при объявлении поля — не нужно наследование и SFINAE/специализации.
* **Работает с `final`-классами.**
* Не засоряет пространство имён класса методами базового класса.

*(Примечание: компилятор MSVC для сохранения бинарной совместимости ABI использует собственный синтаксис `[[msvc::no_unique_address]]` вместо стандартного атрибута в режиме C++20).*

---

## Сравнение подходов (на 64-битной архитектуре)

| Вариант | `sizeof` с обычным пустым классом | `sizeof` с `final` пустым классом | Сложность реализации |
| :--- | :---: | :---: | :--- |
| **Без оптимизации (`NaivePtr`)** | 16 байт | 16 байт | Минимальная |
| **EBO (`EboPtr`, C++11)** | **8 байт** | 16 байт (не работает) | Высокая (наследование + SFINAE) |
| **`[[no_unique_address]]` (`ModernPtr`, C++20)** | **8 байт** | **8 байт** | Минимальная (1 атрибут) |
