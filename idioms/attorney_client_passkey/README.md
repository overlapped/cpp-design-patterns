# Attorney-Client & Passkey Idioms

## Проблема
Ключевое слово `friend` в C++ работает по принципу «всё или ничего»: объявляя `friend class Other;`, вы открываете классу `Other` доступ ко **всем** приватным полям и методам, нарушая инкапсуляцию.

Обе идиомы решают эту проблему, предоставляя **гранулярный (точечный) контроль доступа**.

---

## 1. Attorney-Client (Адвокат — Клиент)
Между целевым классом (**Client**) и внешним потребителем создаётся класс-посредник (**Attorney**).
* `Client` объявляет другом только `Attorney`.
* `Attorney` содержит набор приватных статических методов-обёрток, делегирующих вызовы строго к разрешённым приватным методам `Client`.
* `Attorney` объявляет друзьями конкретные внешние классы, открывая каждому ровно тот набор методов, который ему нужен.

**Плюсы:** не меняет сигнатуры методов целевого класса; можно создавать разных «адвокатов» для разных групп клиентов.  
**Минусы:** больше шаблонного кода (boilerplate) на написание прокси-класса.

---

## 2. Passkey (Ключ доступа)
Метод в целевом классе объявляется в секции `public`, но принимает фиктивный параметр — шаблонный класс `Passkey<AuthorizedClass>`.
* У `Passkey<T>` конструктор по умолчанию объявлен в `private`, а другом назначен только тип `T`.
* Конструкторы копирования и перемещения удалены (`= delete`), чтобы владелец ключа не мог передать его постороннему коду.
* Вызвать защищённый метод может только `AuthorizedClass`, передав временный экземпляр `Passkey<AuthorizedClass>{}`.

**Плюсы:** минимум кода; универсальный шаблон `Passkey<T>` переиспользуется во всём проекте; нулевые накладные расходы в рантайме (пустой параметр оптимизируется компилятором).  
**Минусы:** метод формально виден в `public`-интерфейсе класса (хотя вызвать его извне невозможно).

---

## Сравнение идиом

| Критерий | Attorney-Client | Passkey |
| :--- | :--- | :--- |
| **Объём кода** | Выше (нужен отдельный класс-посредник) | Минимальный (один шаблон `Passkey<T>` на весь проект) |
| **Публичный API целевого класса** | Остаётся полностью чистым | Защищённые методы находятся в `public` |
| **Выдача прав нескольким классам** | Легко (несколько `friend` в `Attorney`) | Нужны перегрузки или `Passkey<T1, T2...>` (вариативный шаблон) |
| **Overhead в рантайме** | Нулевой (inline-обёртки) | Нулевой (empty struct optimization) |
