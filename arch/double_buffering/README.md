# Double Buffering

Double Buffering - это шаблон проектирования, который позволяет асинхронно обновлять данные, не блокируя основной поток выполнения. Этот шаблон особенно полезен в системах, где требуется обновление данных в фоновом режиме, например, в графических приложениях или системах с высокой производительностью.

## Основные характеристики

1. **Два буфера**: Шаблон использует два буфера фиксированного размера. Один буфер используется для записи новых данных, а другой для чтения готовых данных.
2. **Асинхронное обновление**: Данные записываются в буфер `back()`, а чтение происходит из буфера `front()`. Это позволяет избежать блокировки основного потока на время обновления данных.
3. **Переключение буферов**: Метод `swap()` меняет местами буферы, делая текущий буфер `back()` доступным для чтения и новый буфер `front()` для записи.

## Ограничения

- **Нет потокобезопасности**: Этот шаблон не обеспечивает потокобезопасность. Если несколько потоков будут пытаться использовать этот шаблон одновременно, это может привести к неопределённым поведению. Подробнее о потокобезопасности см. в файле `docs/notes.md`.
