# Memory Pool

Memory Pool - это шаблон проектирования, который позволяет эффективно выделять и освобождать память для объектов одного типа. Этот шаблон особенно полезен в системах, где требуется минимизировать количество выделений и освобождений памяти, например, в графических приложениях или системах с высокой производительностью.

## Основные характеристики

1. **Фиксированный размер блоков**: Шаблон использует фиксированный размер блоков памяти для хранения объектов.
2. **Быстрая выдача и возврат памяти**: Память выделяется из заранее выделенного буфера, а не через оператор `new`. Возврат памяти возвращает блок в буфер для повторного использования.
3. **Ограничение количества блоков**: Шаблон ограничен фиксированным количеством блоков, что позволяет заранее выделить память и избежать динамического выделения во время выполнения.

## Ограничения

- **Нет потокобезопасности**: Этот шаблон не обеспечивает потокобезопасность. Если несколько потоков будут пытаться выделять или освобождать память одновременно, это может привести к неопределённым поведению. Подробнее о потокобезопасности см. в файле `docs/notes.md`.
