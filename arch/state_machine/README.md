# State Machine

Табличная машина состояний с таблицей переходов, фиксированной на этапе компиляции (std::array<Transition, N>) — типичный подход для embedded.

## Файлы

- `state_machine.hpp`: Основной заголовочный файл, содержащий определение класса `StateMachine`.
- `example.cpp`: Пример использования машины состояний.
- `test.cpp`: Тесты для проверки корректности работы машины состояний.

## Ключевые идеи

1. **Табличная структура**: Машина состояний описывается таблицей переходов, где каждый переход задается начальным состоянием, событием, конечным состоянием и действием.
2. **Действия**: Действия, выполняемые при переходах, могут быть определены в виде функций.
3. **Проверка переходов**: Метод `dispatch` позволяет проверить наличие и выполнение перехода.
4. **Тестирование**: Предоставлены тесты для проверки корректности работы машины состояний.

## Ограничения

1. **Ограниченность таблицы переходов**: Таблица переходов должна быть полностью определена при создании машины состояний.
2. **Нет динамического добавления переходов**: Переходы не могут быть добавлены динамически после создания машины состояний.
3. **dispatch возвращает bool: false означает, что перехода для пары (состояние, событие) нет; исключения не бросаются**
