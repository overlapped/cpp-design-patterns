# Active Object

Active Object - это шаблон проектирования, который позволяет выполнять методы в выделенном рабочем потоке, а не в текущем потоке вызова. Этот шаблон особенно полезен в многопоточных системах, где требуется изолировать выполнение длительных операций от основного потока приложения.

## Основные характеристики

1. **Выделенный рабочий поток**: Методы Active Object вызываются из клиентского потока, но выполняются в выделенном рабочем потоке через очередь запросов.
2. **Асинхронное выполнение**: Методы возвращают `std::future`, чтобы клиент мог дождаться результата выполнения.
3. **Очередь запросов**: Все вызовы методов добавляются в очередь и выполняются в порядке их поступления.

## Ограничения

- **Нет потокобезопасности**: Этот шаблон не обеспечивает потокобезопасность. Если несколько потоков будут пытаться вызывать методы Active Object одновременно, это может привести к неопределённым поведению. Подробнее о потокобезопасности см. в файле `docs/notes.md`.
