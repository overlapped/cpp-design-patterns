# Watchdog

Watchdog - это шаблон проектирования, который позволяет отслеживать время и оповещать о его истечении. Этот шаблон особенно полезен в системах, где требуется мониторинг состояния или выполнение операций с таймаутом.

## Основные характеристики

1. **Ручное управление временем**: Время передаётся снаружи, что делает класс детерминированным и удобным для тестов.
2. **Запуск и перезапуск**: Метод `start()` запускает или перезапускает отсчёт с текущего момента.
3. **Сброс таймаута**: Метод `kick()` сбрасывает дедлайн от текущего момента.
4. **Проверка истечения таймаута**: Метод `expired()` проверяет, не истек ли таймаут.
5. **Диагностика**: Метод `remaining()` возвращает оставшееся время до истечения таймаута.

## Ограничения

- **Нет потокобезопасности**: Этот шаблон не обеспечивает потокобезопасность. Если несколько потоков будут пытаться использовать этот шаблон одновременно, это может привести к неопределённым поведению. Подробнее о потокобезопасности см. в файле `docs/notes.md`.
